## Guides and reputation
The route template `/guides/[slug]` is implemented. `frontend/src/content/guides.ts` is intentionally empty until a real author/reviewer, original image rights, verified facts, publication/update dates and actual product links are supplied. Missing guides return 404, not placeholder articles.

Editorial briefs, in priority order:
1. **What a three-piece unstitched set includes**: photograph and inventory one actual stocked set; label each included component and its measured length; explain that shawl/dupatta contents differ by item; link verified SKUs and the return policy.
2. **How to assess Boski online**: use the actual stocked Boski item, supplier documentation, close-up photos, measured dimensions and limitations of online assessment. Don't imply silk content or authenticity without proof.
3. **Care for a specific stocked fabric**: transcribe the verified supplier/garment care label and document limitations. No generic washing-temperature promises.
4. **Budget-based buying**: derive current price ranges from available variants, date the comparison and refresh stock/price before publication. Avoid frozen price claims in evergreen headings.
5. **Dhanak versus khaddar**: hold until actual samples and merchant-verified composition/construction for both are available; the baseline contained no stocked khaddar category. Use an honest comparison with sample photos and named reviewer, not invented tests.

Publish two reviewed guides monthly after catalog completion. Add published guides to the sitemap and relevant category/product links. Use only owner-verified social/store profiles. Request genuine reviews after delivery; disclose incentives if used. Seek relevant independent textile/fashion coverage only after owner authorizes outreach. Google Business Profile is appropriate only if actual customer-facing/service-area eligibility is met, not for an online-only store by default. Never buy spam links or manufacture testimonials.
